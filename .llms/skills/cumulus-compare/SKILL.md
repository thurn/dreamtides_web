---
name: cumulus-compare
description: Locate image artifacts generated by npm run compare-cumulus-scene
---

Run `npm run compare-cumulus-scene` from the repository root, then compare `cumulus/Artifacts/SceneComparison/<scene-id>/<width>x<height>/web.png` with `unity.png` or use `report/difference-4x.png` and `report/split-web-left-unity-right.png` from the same directory.

Inspect every generated artifact and record a cold conclusion about the visible
differences. A whole-frame score can hide a missing localized effect when the
unchanged backdrop dominates the pixels. For material or lighting claims, pair
the whole-frame comparison with same-scene on/off captures, a nonzero
target-region contribution, the expected direction of change, and a deliberately
broken negative control that fails.
