Pre-existing: Tango design-system audit follow-ups remain
==========================================================

The Tango readiness pass added missing workhorse component docs/demos, current
screen-composition guidance, the `essence` and `reward` QA scenes, route context
for site registry screens, popup guidance for InfoCard versus HoverPopover, and
a Tango-scoped `no-name-keyed-cards` lint rule.

The broader system-audit checklist still needs a dedicated design-system pass:
glass button-suite consolidation, glass material consolidation, generated
adoption counts in Tango docs, catalog deletions, ResourceChip/EssenceValue
economy-mark convergence, dead-token pruning, atlas demo representativeness
repairs, and the larger component-convergence folds.


Pre-existing: npm audit reports firebase-tools dependency vulnerabilities
=========================================================================

Non-breaking audit fixes have been applied, but `npm audit --audit-level=moderate`
still reports 3 moderate findings through `firebase-tools` dependencies
(`@google-cloud/pubsub` / `@opentelemetry/core`). The only automated fix offered
by npm is `npm audit fix --force`, which installs `firebase-tools@14.23.0` as a
breaking downgrade from the current 15.x line. Resolving this safely needs an
explicit toolchain decision rather than an automatic forced downgrade.
