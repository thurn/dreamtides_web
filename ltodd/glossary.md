# Glossary

This book-level reference defines Dreamtides' canonical player-facing terms in
alphabetical order. Read it when resolving terminology across parts; each term
links to the chapter that owns its complete rules or presentation.

## Battle

A two-player Card game between the player and an automated opponent, played as
part of a Dream Journey. See the
[Dreamtides introduction](dreamtides/dreamtides.md).

## Battle card

One specific card in a battle, with its own battle card ID and battle-local
state. It may record the card instance from which it was created. See the
[foundations chapter](dreamtides/dreamtides.md).

## Card

An authored Character or Event definition, a card instance in a journey, or a
battle card. Use the qualified term when the distinction matters. See the
[foundations chapter](dreamtides/dreamtides.md).

## Card definition

The immutable authored record for a Card, identified by a stable UUID. See the
[foundations chapter](dreamtides/dreamtides.md).

## Card instance

One specific card owned during a journey, with its own instance ID and
persistent modifications. See the
[foundations chapter](dreamtides/dreamtides.md).

## Card status

An optional, unordered classification such as Starter, Legendary, Special, or
Tutorial. See the [foundations chapter](dreamtides/dreamtides.md).

## Character

The Card type that has Spark and can participate in Challenges. See the
[foundations chapter](dreamtides/dreamtides.md).

## Created Card

A battle card produced by a game rule rather than drawn from the battle deck.
See the [foundations chapter](dreamtides/dreamtides.md).

## Deck entry

One card instance in the journey deck, including modifications to that specific
copy. See the [foundations chapter](dreamtides/dreamtides.md).

## Definition ID

The stable ID of the authored or derived definition from which an object starts.
See the [foundations chapter](dreamtides/dreamtides.md).

## Dream Avatar

The authored character selected for a journey, including its ability, starting
Essence, and signature Cards. See the
[foundations chapter](dreamtides/dreamtides.md).

## Dream Journey

One complete run through the Dream Atlas, including deckbuilding Sites and
Battles. See the [Dreamtides introduction](dreamtides/dreamtides.md).

## Dreamsign

An authored passive effect collected during a journey. See the
[foundations chapter](dreamtides/dreamtides.md).

## Dreamwell

The shared deck that increases each participant's Energy production during a
Battle. See the [Dreamtides introduction](dreamtides/dreamtides.md).

## Energy

The Battle resource spent to play Cards and activate abilities. See the
[foundations chapter](dreamtides/dreamtides.md).

## Essence

The currency gained and spent during a Dream Journey. See the
[foundations chapter](dreamtides/dreamtides.md).

## Event

The Card type that resolves its effect instead of entering play as a Character.
See the [foundations chapter](dreamtides/dreamtides.md).

## Figment

A catalog-defined created Character. See the
[foundations chapter](dreamtides/dreamtides.md).

## Instance ID

The ID of one concrete occurrence of an object in game state. See the
[foundations chapter](dreamtides/dreamtides.md).

## Memory

A Battle resource stored by a battle card for later effects. See the
[foundations chapter](dreamtides/dreamtides.md).

## Points

The Battle resource used to measure progress toward a scoring target. See the
[foundations chapter](dreamtides/dreamtides.md).

## Rules text

Authored instructions associated with a specific game-object definition. See the
[foundations chapter](dreamtides/dreamtides.md).

## Spark

A Character's power when resolving a Challenge. See the
[foundations chapter](dreamtides/dreamtides.md).
