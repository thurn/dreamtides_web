# Avatar Signature Cards — MTG Names

The MTG card (`mtg-name`) that each Avatar signature card was reskinned
from. Signatures come from the `signature-cards` field in
`data/avatars.toml`; the `mtg-name` for each
Dreamtides card name is read from `data/cards.toml`. Each
Avatar heading also shows its own title and ability from
`data/avatars.toml`.
