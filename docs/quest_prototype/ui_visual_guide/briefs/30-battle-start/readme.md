# Brief 30 — Battle Start (Pre-Battle Intro)

**Screen.** Battle Start: the pre-battle intro to scout the opposing Dreamcaller (ability, signature cards, dreamsigns, stakes) before "Begin Battle".

**Where to read more.** See the **"Battle Start (Pre-Battle Intro)"** section of [battle_ui_visual_guide.md](battle_ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 30 places it in the larger redesign work-list. Reference screenshot: [03a-battle-start.png](03a-battle-start.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
