# Brief 03 — Persistent HUD (Bottom Bar)

**Screen.** The always-on bottom bar carrying run state (essence, deck size, Dreamcaller, dreamsigns, progress) plus the global controls; it surrounds every meta screen.

**Where to read more.** See the **"Persistent HUD (Bottom Bar)"** section of [ui_visual_guide.md](ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 3 places it in the larger redesign work-list. Reference screenshot: [22-dreamcaller-popover.png](22-dreamcaller-popover.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
