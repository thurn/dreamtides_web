# Brief 08 — Dreamscape Screen

**Screen.** The inside-a-dreamscape view: a scatter of clickable site nodes over the dreamscape's scene art.

**Where to read more.** See the **"Dreamscape Screen"** section of [ui_visual_guide.md](ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 8 places it in the larger redesign work-list. Reference screenshots: [05-dreamscape.png](05-dreamscape.png), [05b-dreamscape-site-hover.png](05b-dreamscape-site-hover.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
