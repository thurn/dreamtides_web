# Brief 36 — Choice Prompt

**Screen.** The Choice Prompt: a yes/no-or-pick-an-option blocking modal - the option-button sibling of the Card Picker.

**Where to read more.** See the **"Choice Prompt Overlay"** section of [battle_ui_visual_guide.md](battle_ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 36 places it in the larger redesign work-list. (No screenshot of this surface is captured in the guide.) Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
