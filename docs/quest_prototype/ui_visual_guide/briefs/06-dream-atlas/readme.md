# Brief 06 — Dream Atlas

**Screen.** The between-dreamscapes world map: a 7-layer branching graph and the run's primary navigation hub.

**Where to read more.** See the **"Dream Atlas"** section of [ui_visual_guide.md](ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 6 places it in the larger redesign work-list. Reference screenshots: [02-dream-atlas.png](02-dream-atlas.png), [07-atlas-dreamscape-preview.png](07-atlas-dreamscape-preview.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
