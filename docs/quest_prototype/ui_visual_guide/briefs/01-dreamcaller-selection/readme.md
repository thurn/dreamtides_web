# Brief 01 — Dreamcaller Selection

**Screen.** The run-start screen where the player picks 1 of 3 offered Dreamcallers (identity, ability, starting essence, draft direction); the pick bootstraps and immediately begins the entire run.

**Where to read more.** See the **"Dreamcaller Selection (Quest Start)"** section of [ui_visual_guide.md](ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 1 places it in the larger redesign work-list. Reference screenshot: [01-dreamcaller-selection.png](01-dreamcaller-selection.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
