# Brief 47 — Card Note Editor (Developer)

**Screen.** The Card Note Editor: a developer overlay to attach an expiring note to a specific card.

**Where to read more.** See the **"Card Note Editor (Developer)"** section of [battle_ui_visual_guide.md](battle_ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 47 places it in the larger redesign work-list. Reference screenshot: [b14-card-note-editor.png](b14-card-note-editor.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
