# Brief 37 — Foresee Overlay

**Screen.** The Foresee Overlay: look at, act on, or reorder the top N cards of a deck.

**Where to read more.** See the **"Foresee Overlay"** section of [battle_ui_visual_guide.md](battle_ui_visual_guide.md) for the full layout, every click/hover behavior, and the redesign notes; [redesign_screen_list.md](redesign_screen_list.md) item 37 places it in the larger redesign work-list. Reference screenshot: [b06-foresee.png](b06-foresee.png). Game-system context lives in [quests.md](quests.md) (the quest/meta layer) and [battle_rules.md](battle_rules.md) (the underlying card game).

**Scope.** This is a ground-up redesign of this screen for mobile, built on the Dreamtides mobile design system. Treat the current desktop layout documented here as a behavioral reference for *what the screen must do* — not a layout to port — and design fresh for a narrow, touch-first, portrait screen.
