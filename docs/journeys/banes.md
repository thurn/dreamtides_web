# Nightmare

**Nightmare** is the sole Bane card. Journey effects that add, grant, count,
price, protect against, or remove a Bane always operate on Nightmare.

Nightmare is a Special Event card with an energy cost of 0 and the rules text
`Bane.` Its canonical card UUID is `b0a2c3d4-e5f6-4789-8abc-0def12345678`.
Journey state records Nightmare entries with the Bane flag so systems such as
Purge can apply Nightmare-specific pricing.
