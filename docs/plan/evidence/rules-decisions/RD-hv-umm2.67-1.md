# RD-hv-umm2.67-1: "That card's cost" for a card a resolving effect moved is its copiable cost from just before the move
- Ladder: 4 (MTG analog: CR 608.2h, an effect that needs information about an object that has left the zone it was expected in uses the object's last known information); steps 1–3 are silent: no D-, C-, or P-entry covers a card an effect moved, the prototype implements no resolution-time "to" cost (RD-hv-umm2.115-1), and the `~/dreamtides` Rust engine's `trigger_cost` is unimplemented
- rules.md: § Zone Changes → Cards an effect moved; § Keywords and Effects → Discover
- Affects: fcb830e5-85ff-48f3-be1e-46e102a5c8e8
- Why: "You may discard a card to discover a character with cost greater than that card's cost" reads the discarded card after it left the hand. A discarded deck card keeps its copiable cost in the void, but a created card discarded from a hand ceases to exist instead and has no zone to read it in; reading the value as it was just before the move gives every discarded card a cost, and gives the same answer as reading it in the void whenever both exist. The cost is the copiable cost of § Cost changes (after variant transforms and deck-entry modifications, X counting as 0, cost changes ignored), matching the discard-cost capture that "that card's cost" already reads on a cost. "Greater than" is strict: a character with the discarded card's own cost is not offered. The engine form is `costOf(cardsMovedBy(node))`: the interpreter reads the copiable costs of the cards a referenced node moves before that node resolves, records those that changed zones or ceased to exist while it resolved, and replaces the record each time the node resolves again.
