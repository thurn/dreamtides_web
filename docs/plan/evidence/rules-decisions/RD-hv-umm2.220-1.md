# RD-hv-umm2.220-1: Belladonna requires exactly two materialization occasions

- Ladder: 5 (simplest literal reading consistent with the printed text).
- rules.md: § Keywords and Effects → Current-turn occurrences and physical membership → Last current-turn references; § Ability Types → Counting materializations and intervening conditions.
- Affects: d76684c3-797e-44ae-a2ba-333e77d46a4d (read-only consumer owned by hv-umm2.253).
- Decision: "If you materialized 2 characters this turn" requires exactly two successful materialization occasions by that player in the active turn, checked at trigger admission and resolution. "The last one" is the latest actual physical character before testing its current eligibility, with no substitution after departure, cessation, control loss or type change.
- Why: Current rules settle the occurrence count, figments, rematerializations and intervening-condition recheck. D/C/P entries contain no threshold override. The current prototype leaf is pending. The Rust same-UUID text in `client/Assets/StreamingAssets/Tabula/dreamsigns.toml:143` says "2 allies" and instructs triggering a named ability rather than rematerializing; this changed text is not an unchanged-rule precedent under D10.3. Its file SHA-256 is `b6724d4541b3cf6b142aca376ef206ac3249c5bb7337e9d2a7ed77bb3e028224`. The [current official MTG Comprehensive Rules](https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.pdf), rule 603.4, support condition rechecking, not numeric threshold interpretation. The [official Shadows over Innistrad release notes](https://magic.wizards.com/en/news/feature/shadows-over-innistrad-release-notes-2016-03-30) explicitly use a two-or-more threshold for their werewolf analogue. Neither establishes that bare "2" means at least two. The literal exact count is therefore D10.5; the existing bounded condition encodes it once.
- Implementation contract: Synthetic end-of-turn emblems compose the existing exact count with the new last-materialized physical reference. The production Dreamsign's authoring and full acceptance remain with hv-umm2.253.
