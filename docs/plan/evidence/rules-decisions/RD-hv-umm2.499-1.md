# RD-hv-umm2.499-1: "Return all but one character you control to hand" chooses the kept character as it resolves, without targeting, and returns the rest in board order

- Ladder: 4 (MTG Comprehensive Rules 608.2d, adapted: a choice other than modes, targets, costs and X is made while the resolving effect is applied; MTG 115.10, adapted: only targeting is restricted, so a permanent with hexproof or shroud can be chosen by a non-targeted choice), then 5 for "with one character or none, nothing returns" and for the board-order cohort, the simplest readings consistent with the printed text. Step 1 is silent (no D-, C-, or P-entry names this card or "all but one"); step 2 is silent (the prototype has no such effect); step 3 is silent (the `~/dreamtides` Rust engine parses "all but one ally" only as a cost collection expression, with different rules text, and implements no mutation for it).
- rules.md: § Keywords and Effects → Return to hand; § Targeting ("Effects that do not target, such as 'Dissolve all characters', still affect it."); § Zone Changes. RD-hv-umm2.60-1 and RD-hv-umm2.106-1 established the 608.2d resolution-time choice for other effects.
- Affects: f7ffe999-685d-4ea2-85de-2e567eb2a042 (Key to the Moment, authored by composition bead hv-umm2.156), and every later entity that returns all but one character its controller controls.
- Why: "All but one" names a single exception the text never says is targeted, so its controller picks it as the effect resolves, from every character they control in either rank, the effect's own source included when it is a character. A character that cannot be targeted is eligible to be kept, and is returned when it is not kept, as any non-targeting effect reaches it. The cohort is fixed as the choice is made; the other characters return one after another in the engine's board order, back rank before front rank, each left to right, so "When you return a character to hand" triggers queue in that order. With one character there is nothing besides the kept one to return, so no choice is asked; with none, nothing happens. The choice is public, like `abandon`'s, because every candidate is on the battlefield.
- Mechanics: `returnAllButOne({ drawForEach: true })` (`src/engine/effects/primitives/return-all-but-one.ts`) raises a non-cancellable `chooseCards` prompt with the new `keep` role over `charactersInPlay(state, controller)` when there are at least two, then calls the ordinary `returnToHand` zone change for each other cohort member still in play under that controller. The `engine.promptOpened` and `engine.promptAnswered` log records carry the kept instance, and `engine.returnedToHand` each return.
- Contracts: `return-all-but-one.contracts.ts`.
