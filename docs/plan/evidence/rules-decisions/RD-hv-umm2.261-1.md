# RD-hv-umm2.261-1: Original journey transformations and prepared site allowances
- Ladder: 4 for occurrence versus existing state: Magic Comprehensive Rules effective September 25, 2026, 603.2e and 603.2g ([official rules](https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt)); adapted to a journey transformation operation. Step 5 for multiple replacement sources setting the same two-card allowance and its initial quote lifetime. D39 settles current type and permanent entry modifications.
- rules.md: Journey Transfiguration Effects
- Affects: 0c52e8c3-a792-4eea-955f-a0c61463c066; d9f0f7ff-63c0-4247-8831-054d7fed931d
- Why: A trigger for an operation requires that operation to occur. Gaining a card already carrying a form and copying a transformed card do not transfigure the newly gained entry. Snapshot original entry occurrences once before modifier dispatch; source-generated copies cannot retrigger the same operation. Copies retain the transformed entry's form, permanent modifiers and explicit stat overrides, while their physical identity is new. Each Leaf replacement sets the allowance to its printed two, so multiple sources produce the same allowance. Preparing the allowance with immutable site offers gives it the same replay and source-loss lifetime as that quote.
- Earlier ladder evidence: The three scoped prototype leaves were pending at base 04620bd69e8ecec9f80d7a3059add40dab0d63bf, with no implementation elsewhere. Existing reward-effect primitives distinguish transfigure_deck_entry, add_catalog_card and duplicate_deck_entry. The actual queued Exploration presentation says the next Draft or Shop contains transfigured cards; offer preparation and taking those cards are distinct from modifying an original journey entry. Read-only searches of the Rust engine's .rs sources for transfigur and the three source names, and its battle_rules.md for transfig/journey, found no applicable unchanged journey rule or body. Magic's double-face transformation action (701.27) does not define journey badge eligibility or site allowance; only its event/state trigger principle is adopted here.
