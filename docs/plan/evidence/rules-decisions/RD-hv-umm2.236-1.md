The optional base replaces normal ●, including printed energy-X (fixed0), but retains additional costs, increases and reductions. A separate count-only X remains prepared normally. The rule supplies no timing or zone access. An independent void/deck permission supports this route and is consumed normally; Offering or Reclaim supplies its own alternative. Plain Reclaim keeps the normal numeric base in this engine but remains a Reclaim route, like flashback with an unchanged amount; it cannot supply access for another alternative cost. Copies of the rule add one equivalent option. The UI identifies this route without promising its printed base as the final debit.
