# RD-hv-umm2.143-1: Burst of Obliteration may be played for X = 0, and either mode may then be chosen

- Ladder: 4 (MTG Banefire, the card's `mtgName`, may be cast with X = 0), then 5 for the contextual meaningful-mode reading consistent with the printed text. rules.md § Costs, Requirements, and X → X costs and § Modal abilities, with RD-hv-umm2.140-1 (Grounded) and RD-hv-umm2.145-1 (Collateral Damage), supply the normative X and mode rules. No D-, C-, or P-entry names this card, and steps 2–3 give no implementation of it.
- rules.md: § Costs, Requirements, and X → X costs.
- Affects: 1c8e6736-13d6-42d1-8668-46f422fec11e (Burst of Obliteration, "Choose one: Gain X⍟ or dissolve an enemy with X✦."; base, it has no amplified text).
- Why: the X minimum is authored per card (`xMinimum`), not per mode, so one value covers both modes. Dissolving an enemy with exactly 0✦ is a meaningful effect: catalog characters print 0✦ and spark changes bring others to 0✦, and an exact bound of 1 or more could never reach them, so a minimum of 1 would remove part of what the printed dissolve mode can do. A minimum of 0 keeps every target the text names. Its cost is that X = 0 also permits the gain mode, which gains nothing; this is the same contextual trade Collateral Damage accepts on a board with no 0✦ character. Mode legality already reads the picked X, so at X = 0 the dissolve mode is offered only while an enemy has exactly 0✦, and otherwise the gain mode is the only legal mode.
- Mechanics: `xMinimum: 0` and `event(p.chooseOne(p.gainPoints(x()), p.dissolve(target(enemyCharacter({ sparkAtLeast: x(), sparkAtMost: x() })))))`. The play step picks X (`chooseX`), then the mode (`chooseModes`, whose `modeLegal` passes the picked X as `selectorX`), then the target, whose paired spark bounds read the paid X as it is offered and again as it resolves; no engine change.
