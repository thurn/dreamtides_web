# RD-hv-7x4l.8-5: Phasing moves the character by its effect, front rank included
- Ladder: 5 (simplest reading consistent with both Phasing cards)
- rules.md: § Keywords and Effects → Phasing
- Affects: 071bcab4-ed02-48a0-93dc-8fd0f36611c8, 2f5cc27f-db6e-4bc8-bfa2-eeacebae57f7
- Why: Phasing's character has just materialized, so it is exhausted unless awakened, and the repositioning rule keeps an exhausted character out of the front rank. Applying that rule would make Phasing do nothing for front-rank positions. The move is part of the ability's effect, like gain control, so it is not a player's repositioning: the character moves to the returned character's position in either rank. It moves only if it is still in play on the same side and the position is open after the return.
