# RD-hv-umm2.87-2: "Until end of turn, events in your void gain reclaim" gives Reclaim to the events in that void as it resolves
- Ladder: 4 (MTG 611.2c: a continuous effect from a resolving spell that changes characteristics affects only the objects determined as it resolves; Past in Flames, From the Barrow's reference card, gives flashback only to the cards in the graveyard as it resolves). rules.md § Spark → Values fixed as an effect resolves and § Keywords and Effects → Reclaim, with RD-hv-umm2.78-1, supply the normative fixed-set, granted-Reclaim, duration and cost rules. Step 3 is silent (the Rust engine implements no granted Reclaim, RD-hv-umm2.78-1).
- rules.md: § Keywords and Effects → Reclaim
- Affects: 4752fc43-6696-4bc3-88d0-4d5b97622fa8 (From the Barrow, "Until end of turn, events in your void gain reclaim"); later group grants of Reclaim from a resolving effect
- Why: rules.md fixed the affected set only for changes to characters. A group grant of Reclaim is the same kind of change, a keyword for a while, so it reaches the events in the void as the effect resolves. From the Barrow is on the stack then, so it does not grant Reclaim to itself; an event put into the void later in the turn, From the Barrow itself after it resolves included, does not gain it. Each gain is plain Reclaim, so an event with a printed Reclaim cost keeps it, and each ends with the turn wherever its card is.
- Mechanics: `grantReclaim(everyIn("void", { cardType: "event" }), { duration: untilEndOfTurn() })` resolves its cards once (`src/engine/effects/primitives/grant-reclaim.ts`) and starts one floating keyword change for each, announced by `effectStarted` and ended in the Ending phase. A gained Reclaim is a play permission, so `carriesLegality` (`src/engine/rules/floating.ts`) keeps it with a redacted source in every view and determinization: a copy of From the Barrow ceases to exist as it resolves, and its grants still make the events playable from the void in every determinization.
