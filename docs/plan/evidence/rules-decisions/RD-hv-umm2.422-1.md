# RD-hv-umm2.422-1: Explicit replacement routes replace an own normal-base setter

- Ladder: 4, verified MTG analog. D10 steps 1–3 supply no own-setter route precedence decision: no explicit project decision, no actual prototype setter rule, and no unchanged Rust setter wording. Rust's unchanged Reclaim alternative wording establishes its route, not setter precedence.
- Sections: rules.md § Costs, Requirements, and X → A card's own cost; § Keywords and Effects → Reclaim and Offering.
- Affects: 5aaf13de-25bc-467f-a4a0-fe2c4373cc9f and 7f550d4e-c6a1-4e5e-ae0c-1b3edd6f0f4a; general for any own "It costs N●" setter. No immutable content changes.
- Decision: an own setter defines the normal ● base. A normal hand play, play permission or plain Reclaim uses the latest set. Explicit printed or granted Reclaim and Offering select a replacement base, which does not include that own setter. Chosen route X and all additional mandatory, optional and alternative-choice payments still add to the selected base. Own-card increases and all numeric increases/reductions apply on every route, followed by the zero floor. Cost filters use unchanged copiable cost. Static nth-player cost wording is a separate rule decision.
- Rationale: alternatives in the additional-cost section choose an additional payment; choosing a full Reclaim or Offering route selects a payment base. Selecting one base avoids treating a set-to-printed-cost effect as a surcharge on a replacement route. Printed 2● / set 2● / Reclaim 5● therefore pays 5●. Offering / set 2● / optional 1● pays 1●. Explicit Reclaim 0● / set 0● / optional 1● also pays 1●.

These rules distinguish the original characteristic from the selected payment base and then compose additional payments, increases and reductions; they are an analogy adapted to Dreamtides' own setter and keyword wording.
