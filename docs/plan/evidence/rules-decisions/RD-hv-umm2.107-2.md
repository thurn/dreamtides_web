# RD-hv-umm2.107-2: "When you materialize a spirit animal, if it is not the first spirit animal you have materialized this turn" triggers for every matching materialization after the first, which stays true as it resolves
- Ladder: 1 (rules.md § Ability Types → Intervening conditions: "When X, if Y" triggers only if Y holds as X happens and does nothing unless Y still holds as it resolves; § Ability Types → Counting materializations, RD-hv-umm2.107-1, for what counts), then 5 (the simplest reading consistent with the text: "not the first" is "the second or later" by the same count)
- rules.md: § Ability Types → Counting materializations
- Affects: f38ab9b6-bea7-4c6e-b5db-2609796ba46b (Dawnprowler)
- Why: Y is "this materialization is not the first matching one this turn". The turn's materializations only grow, never shrink or reorder, until the turn ends, and a triggered ability resolves before any player receives priority, so before the turn can end: a materialization that was not the first as it triggered is still not the first as it resolves. Checking Y as the trigger matches is therefore the whole intervening condition. Dawnprowler is a spirit animal, so when it enters as the turn's first spirit animal it sees itself as the first and does not gain; it gains from every later one.
- Mechanics: `whenMaterialize(characterYouControl({ subtype: "Spirit Animal" }), { atLeast: 2 })` (`MaterializeNth`'s `{ atLeast }` form in `src/engine/dsl/types.ts`), matched in `src/engine/triggers/matcher.ts` when the count of matching records, the triggering one included, is at least 2; no `Condition` kind is added.
