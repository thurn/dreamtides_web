# RD-hv-7x4l.7-2: Continuous effects apply by layer, then timestamp; ties go to static abilities in source order, then floating effects in creation order
- Ladder: 4 (MTG 613: layers, then timestamp order within a layer; MTG 613.7 leaves simultaneous timestamps to a player's choice, which D14's "no ordering prompts" rules out)
- rules.md: § Ability Types → Order of continuous effects
- Affects: every static ability and every effect with a duration that changes types, keywords, base spark, spark, or costs
- Why: rules.md had no order for conflicting continuous effects, such as a keyword granted and removed, or two base-spark settings. The engine uses engine-design's layers (types, abilities, base spark, spark, cost) and timestamp order within each: a static ability's timestamp is its source's zone-entry time (0 for an avatar or dreamsign), an effect with a duration's is the zone-entry clock when it began. The clock ticks only on zone entry, so a trigger's effect can share a timestamp with the card whose arrival caused it. Ties resolve without a prompt (D14 style): static abilities before effects with a duration, so an effect created at the same moment as a static's source is treated as newer; static abilities in a fixed source order (player avatar, player dreamsigns, enemy avatar, enemy dreamsigns, then cards by creation order), never by board position, so characteristics do not flip when cards move; effects with a duration in creation order. A static ability's selectors and values read the characteristics of the layers before its own (a spark anthem sees base spark, not other spark changes), so no layer depends on itself and the evaluation always terminates.
