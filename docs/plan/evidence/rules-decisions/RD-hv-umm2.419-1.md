# RD-hv-umm2.419-1: A card cost setter defines the normal energy base

- Authority: rules.md § Costs, Requirements, and X → A card's own cost; § Keywords and Effects → Reclaim and Offering; RD-hv-umm2.422-1 (D10 ladder 4).
- Rule: normal hand plays, void play permissions and plain Reclaim use the latest own "It costs N●" base setter. Explicit printed or granted Reclaim and Offering choose replacement route costs in place of that normal base. X and additional mandatory, optional or alternative-choice costs add to the chosen base. Increases, reductions and the zero floor apply to that total. The latest applicable explicit Reclaim grant supplies the replacement costs; a plain grant preserves the applicable cost.
- Examples: a printed 2● card set to 0● with explicit Reclaim 0● and an accepted optional 1● payment costs 1●. With explicit Reclaim 5● it costs 5● even if its own setter is 2●. A normal-cost play permission uses the latest own setter. Offering with a set of 2● and an accepted optional 1● payment costs 1● and pays its hand banishment.
- Implementation: one private explicit-Reclaim selection seam supplies route costs and identifies full replacement routes. The route modifier excludes own base setters on those routes while retaining own-card increases and every numeric increase or reduction. Normal routes and display apply own setters against copiable cost. Payment and X affordability use the actually chosen route. State holds the existing effects and prompt answers; setter applicability is computed from that route.
- Evidence: public synthetic modify-card-cost-routes contracts cover route alternatives, grants, optional/X/composed payments and fold cancellation/reload. The four zero-set payment witnesses remain passing. Historical hv-umm2.419 browser evidence is tied to source efb6ef56651eb9d4fa5d6fb5425326d5089ed29d; it exercises zero setters and is not a browser run of hv-umm2.422.
- Ladder: D10 step 4, as detailed in RD-hv-umm2.422-1. The official MTG Comprehensive Rules effective 2026-09-25, CR 118.9c/d and 601.2b/f, distinguish choosing a normal or alternative base from adding additional payments and cost adjustments.
