# RD-hv-umm2.101-1: "It costs N●" sets the card's base energy in place of its ● cost, ahead of increases and reductions; the latest set applies
- Ladder: 4 (MTG analog: CR 601.2f totals a spell's cost from its mana cost or an alternative cost, then adds additional costs and increases, then subtracts reductions; a characteristic set by a later effect overrides an earlier one, as in layer timestamp order)
- rules.md: § Costs, Requirements, and X → A card's own cost
- Affects: 5aaf13de-25bc-467f-a4a0-fe2c4373cc9f (The Bondweaver), 7f550d4e-c6a1-4e5e-ae0c-1b3edd6f0f4a (Ethereal Courser); general for every "It costs N●" change
- Why: Treating the set cost as the card's starting ● cost keeps every other cost change meaningful ("Characters cost 1● more" still taxes a card set to 0●) and keeps X, additional energy costs, and chosen alternative or optional energy costs paid on top of it, so a set never makes an X card's X free. Several sets on one card resolve by timestamp, the latest applying. The engine applies the set as the difference between the set value and the selected route's ordinary energy component, joined to the increases or the reductions (continuous/costs.ts `costModifier`): that component is the copiable cost for normal routes and plain Reclaim, or 0 for explicit Reclaim and Offering. With the floor of 0● applied only to the total, the set value starts the ordinary component while chosen route energy remains on top. The card's cost for conditions stays its copiable cost.
