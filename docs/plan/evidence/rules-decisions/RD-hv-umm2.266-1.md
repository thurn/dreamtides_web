Additional options join the site's existing ware category on each fresh
preparation. Held physical copies add their printed amounts. Existing shelves
persist through source changes and reload; the next successful Restock uses
current holdings. Safe integer count arithmetic prevents partial preparation.

A first-Restock source reads the visit's successful count, with the existing
global free-Restock pool taking priority and being consumed first. Multiple
first-free sources share that one ordinal. Failure changes neither money,
charges nor ordinal. Normal limits and enhanced prices remain authoritative.
The same quote drives both visible Restock surfaces and payment.

A card purchase receives its form before post-domain added-card observers, using
the existing current-entry eligibility provider. Existing forms and an empty
applicable set use no draw and preserve the purchase. An unavailable provider
refuses preparation; a thrown provider or invalid draw is contained by the
ordinary transactional fold. A successful form carries diagnostic UUID, held
index, physical entry, applicable forms and actual draw index. That diagnostic
is not an eligibility permission.

A preformed purchase is an added card under RD261-1, so Spell Tome's original-entry
transformation collector receives no occurrence. Blue Crystal retains the form.
Other added-card effects observe the current physical entry through their
existing held-order waves. Purchase receipts, Essence and free-purchase charges
retain the validated transaction even when a later addition prohibition excludes
that attempted new entry.
