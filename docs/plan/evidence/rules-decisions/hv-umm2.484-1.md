A singular character from the controller's hand is chosen privately at resolution using its current effective character type and copiable cost. A resolving maximum uses existing ValueExpr semantics, including stored counters. An empty matching hand does nothing. Optionality is an independent confirmation. Ordinary materialization preserves physical identity and ownership, takes the leftmost open back slot exhausted unless Awakened, and fires arrival triggers without a play action or printed payment. A full back rank retains the selected card in hand. Existing knowledge of an unchosen card remains governed by visibility rules.

The rules describe all-zone, random, self, deck and void materialization; this additive paragraph settles the singular held-hand instruction without changing those forms. No production UUID or immutable catalog data is authored by this foundation.
