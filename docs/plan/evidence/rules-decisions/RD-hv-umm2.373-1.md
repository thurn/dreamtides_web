# RD-hv-umm2.373-1: “Was reclaimed” checks the source's latest actual committed play method

- Ladder: 4 (MTG analog: “escaped” records an actual cast using the escape ability; stack copies are not cast. Adapted to the actual Reclaim play method, with D15 binding copy behavior).
- rules.md: § Keywords and Effects → Reclaim → Was reclaimed.
- Affects: 6f0b709d-0f57-46de-bfba-6a8b4df2b991 and 74e82d0d-e107-4207-ad2a-73d016ea54a9; any source using `sourceWasReclaimed`.
- Why: The Reclaim rules distinguish the method of playing a card from its mutable reclaimed zone-change replacement status, which abilities can remove. Removing that replacement does not undo the earlier play. The source records whether its latest actual committed play used Reclaim, and each new actual play updates that record. Dreamtides card identity and persistent statuses travel across zones (rules § Zone Changes), so materializing without playing keeps the latest play method. The MTG analogy supplies the actual-play criterion; Dreamtides identity rules govern its lifetime. A created stack copy is not played and starts with false provenance; X and paid additional costs are the properties D15 carries from the original. A missing source or emblem was not itself played via Reclaim and satisfies the false branch.
- Evidence: The prototype has mutable reclaimed replacement state but no implementation of this conditional. The unchanged Rust Reclaim rules and reclaim tests describe the replacement and contain no conditional play-provenance form. They do not decide the past-tense condition. The current printed text uses “If you reclaimed this card” rather than a present-status check, so the simplest reading records the actual play method independently.

- Analog sources: [Theros Beyond Death release notes](https://magic.wizards.com/en/news/feature/theros-beyond-death-release-notes-2020-01-10) define escaped status by the actual graveyard cast using an escape ability; [March of the Machine release notes](https://magic.wizards.com/en/news/feature/march-of-the-machine-release-notes) explain that copies created on the stack are not cast. The adaptation preserves actual play history independently of a removable zone-change replacement.
