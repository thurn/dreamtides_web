# RD-hv-7x4l.9-2: "Exactly the same state" ignores bookkeeping and zone-entry times but keeps their order, and may be noticed a few cycles late
- Ladder: 4 (MTG 104.4b: a loop of mandatory actions that nobody can stop is a draw), then 5 for what "exactly the same" compares
- rules.md: § Infinite Loops → Mandatory Loops
- Affects: no catalog card yet; any triggered abilities that keep triggering each other
- Why: the battle state also records bookkeeping that no rule reads: a step counter, the count of automatic steps, the loop tracker, and a clock that stamps each zone entry. A cycle that moves a card between zones advances that clock on every pass, so comparing it literally would let no such cycle repeat and every one would run to the 100,000-step cap. Only the order of zone entries matters to the rules (layer ordering), so the comparison keeps the order and drops the times. Minted instance and effect numbers and random-stream positions do affect later play (new cards, the next random result), so they stay: a cycle that creates and destroys cards or draws random numbers is not an exact repeat and ends at the resolution cap instead, also a draw. The engine checks for a repeat only once a run of automatic steps reaches the battle data module's threshold (64), and with constant memory (Brent's method), so it may end the battle a few cycles after the first repeat. The result is the same draw. Repetitions of an optional loop are the player's own actions, not automatic ones, so they never end the battle this way even when a repetition changes nothing.
