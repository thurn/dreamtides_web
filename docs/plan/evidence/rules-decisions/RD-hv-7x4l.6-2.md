# RD-hv-7x4l.6-2: An intervening "if" is checked when the ability triggers and again when it resolves
- Ladder: 4 (MTG 603.4: a triggered ability with an intervening "if" clause triggers only if the condition is true, and does nothing on resolution unless it is still true)
- rules.md: § Ability Types → Intervening conditions
- Affects: 4edf2d8d-61e4-4c3a-a388-4b52b2ebd005, 831bc7cf-e8c9-4943-8156-91b7397ef849 ("▸Dawn: If this card is in your void, …"), and every "When X, if Y" ability
- Why: rules.md did not say when a triggered ability's condition is checked. Triggers queue (D14), so the state can change between the event and the resolution, for example when an earlier trigger in the queue moves the card. Checking at both points keeps an ability from triggering when its condition is false and from resolving after an earlier trigger made it false. The engine checks the condition when the ability matches (it never queues otherwise) and again in its `resolveTrigger` step, which emits `triggerResolved` with `applied: false` and does nothing. "If this card is in your void" is both the ability's functional zone (it works only from the void) and its intervening condition.
