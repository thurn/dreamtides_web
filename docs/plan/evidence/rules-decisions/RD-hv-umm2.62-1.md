# RD-hv-umm2.62-1: "Each player" effects resolve for the active player first, then the opposing player, each making their own choices

- Ladder: 4 (MTG analog: CR 101.4, APNAP order for choices and actions of several players), adapted after 1 (D14 already orders simultaneous triggers with the active player's first) and 3 (the `~/dreamtides` Rust engine parses "each player" effects but implements no resolution for them, so it decides nothing).
- rules.md: § Keywords and Effects → Each player.
- Affects: 570895fe-cd21-45d2-89ff-162f46978776, bedee263-27b9-4d73-ab77-6b5c747dff69, 31ecf933-c897-41a5-ab94-822ea65898d8 (base), and the later "each player" texts 0269e363-5567-47a4-80cd-8ebc061fe7e1, 25d00336-5ad7-433b-8ced-71720a9f074a, 475fcc5b-c82d-4ef7-8020-90a8aeb2df53, 06e62e45-53f9-4264-9aa6-2575b445332a, 7171ff89-ebe4-42d0-8863-9b4b0531cad2, a3033051-8eb7-4fbf-93d6-f947ed68974d.
- Why: The rules say nothing about who acts first when an effect makes both players act, or who chooses. MTG has the active player choose first, then the others, with face-down choices from hidden zones, before the actions happen together. Dreamtides already fixes the active player's triggers first (D14), so turn order is the familiar tiebreak and holds whoever controls the effect. Each player chooses for their own part ("you" is that player), so the discarding player picks the discarded card from their own hand, as the printed "each player discards a card" says. The engine runs each player's part to completion before the next one, because rules code prompts only between complete mutations (engine-design § The rules-code contract); the opposing player therefore sees the active player's discard, which is public once made, before choosing their own. The difference from MTG's simultaneous action is small and keeps one generic primitive (`eachPlayer`) for every listed text. "Each player discards their hand, then draws 6 cards" reads as two "each player" clauses, every discard before any draw, matching the MTG original's simultaneous discard; with no choices in either clause the outcome is the same either way. A target or mode inside an "each player" effect would be chosen once by the controller for every player's part, so the DSL rejects one; no current text needs it.
