# RD-hv-7x4l.9-1: An optional loop's gain is judged per resource, deck size counts and void size does not, and the opponent may not have had a decision
- Ladder: 1 (D12: offer the shortcut on "an equivalent state with a monotonic gain"; engine-design § Loops lists the abstracted resources), then 5 for which direction of each resource is a gain
- rules.md: § Infinite Loops → Optional Loops
- Affects: no catalog card yet (every catalog entry is pending); the shortcut applies to any card that builds a repeatable sequence
- Why: rules.md said the differences must have "gained something for that player and nothing for the opponent" without saying which direction of each difference is a gain. Victory points, current and maximum ●, counters, and gained spark are worth more when larger. Cards in a deck are too: fewer brings fatigue nearer, so a loop that draws its player's deck down is not offered, while one that mills the opponent is a gain. Void sizes and turn counts are abstracted so that playing and recycling cards can repeat, but whether more cards in a void helps depends on the cards, so they count neither as a gain nor as a loss. The comparison is per resource and per side: none of the player's may fall, none of the opponent's may rise, and one must change. Counters and gained spark are summed over the cards each side controls. The equivalent position must be in the same main window (one player's Day, Dusk, or Night of one turn), since a turn's phases never repeat. A sequence in which the opponent had a decision — a response other than passing, or a choice with more than one option — is not the player's own loop, and repeating it would make the opponent's choices for them, so it is never offered. When several earlier positions match, the latest one with a gain defines the loop, the shortest sequence.
