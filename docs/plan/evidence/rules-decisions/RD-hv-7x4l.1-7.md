# RD-hv-7x4l.1-7: Victory is a state-based check after every game action; simultaneous wins are a draw
- Ladder: 1 (P5 victory checks; F4 turn limit 50; P11 the limit counts rounds)
- rules.md: § Objective → Victory check
- Affects: general
- Why: rules.md said "the first player to reach the threshold wins" without saying when that is checked. P5 runs the check after every step, so a player wins partway through a phase (for example after one challenge lane), both players reaching the target in the same check is a draw, and passing the turn limit is a draw. The round definition is RD-hv-7x4l.1-22.
