# RD-hv-umm2.145-1: "Dissolve each ≤X✦ character" affects both players' characters and allows X = 0
- Ladder: 2 (rules.md § Costs, Requirements, and X → X costs leaves 0 for X to context; § Spark → Spark outside play makes a ✦ criterion compare a character's effective spark in play; § Targeting says effects such as "Dissolve all characters" do not target), supported by 4 (MTG The Meathook Massacre, the card's `mtgName`, which gives each creature on both sides −X/−X and may be cast with X = 0)
- rules.md: § Keywords and Effects → Dissolve
- Affects: 4cece464-2fde-483d-af92-04cd0341be5b (Collateral Damage, base; it has no amplified text)
- Why: "each … character" names no controller, so it reads every character in play, the caster's own included, as other unqualified "character" text does. The ✦ bound reads each character's effective spark as the effect resolves, with no target chosen as the card is played, so a character's spark changing in response changes whether it is dissolved. Eighteen catalog characters print 0✦, and spark changes can bring others to 0✦, so X = 0 dissolves something on a typical board and is a meaningful play for 2●; the card's `xMinimum` is 0, as RD-hv-umm2.86-2 records for Borrowed Minutes' cost bound. A dissolve by an effect the opponent controls still removes Veil instead (§ Zone Changes, rule 3), so the caster's enemies with Veil lose Veil while the caster's own Veil characters are dissolved. The reference engine's card of this name prints different text and does not bear on it.
- Mechanics: `event(p.dissolve(all(anyCharacter({ sparkAtMost: x() }))))` with `energyCosts: ["2", "X"]` and `xMinimum: 0`; the `all` selector resolves through `selectorMatches` in `src/engine/dsl/selectors.ts`, whose `sparkAtMost` bound reads the paid X; no engine change.
