# RD-hv-umm2.647-1 — unavoidable choices in mandatory copy continuations

D12 requires an unbreakable mandatory continuation to draw. A choice with
multiple legal targets or modes is a genuine choice; it does not establish
that any of its answers can leave the sequence. Under D10's binding-decision
precedence, supported copy continuations whose every legal answer preserves
an infinite trigger FIFO qualify as mandatory.

The tracker proves a conservative event-copy grammar over fixed sources,
universal modes and target domains, and every reachable explicit named
self-renewal body. It rejects stopping or unsupported bodies, modifiers,
possible interfering listeners and live victory predicates. The result is a
proof of continued queue renewal, not equality of states with different
physical copies. At the catalog's mandatory-check threshold, a proved run
draws through the ordinary battle-ended event. No answer is marked forced
merely because it cannot end this continuation.

A genuine choice carries earlier mandatory accounting only when both its
committed start and completed state prove closure. A stopping choice which
enters a closed continuation starts that run at zero. A dormant hand-count
victory prevents certification and retains its eventual win. Exact cycle
hashing, optional Repeat consent, FIFO, priority, prompt fingerprinting,
physical copying and existing resolution/iteration limits retain their
contracts. The proof is transient and adds no persisted or view metadata.

The certified foundation uses named self-renewal with real stack and hand
copies. Its public synthetic contracts include both actors, independent
copy modes and targets, reload/replay and hidden-hand redaction. The current
Trigger union has no creation/copy occasion. The tracker owns an exhaustive
Trigger.on classification: implementing that new occasion requires an
explicit semantic case. Original hv-umm2.233 owns that integration and its
actual typed emission-time hand-copy context, ordinary/Ephemeral/ceased
original cases, creation-driven default-config witnesses, replay/privacy,
weighted 300 battles and browser acceptance. Foundation witnesses do not
claim that consumer acceptance.
