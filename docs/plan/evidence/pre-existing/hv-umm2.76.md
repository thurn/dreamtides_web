# Pre-existing issues found by hv-umm2.76

- `src/engine/dsl/types.ts` (`Condition`, `cond: "cardsIn"`) and `conditionCardCounts` in `src/engine/dsl/builders.ts`: a card-count condition accepts a `filter` on a hand or deck, so a condition such as "if you have two or more events in your hand" would publish, through whether its effect happens, which hidden cards match. RD-hv-umm2.76-1 rules out filtered counts of a hand or deck for values (`CardCountValue`); no authored card uses a filtered hand or deck condition yet. Restricting the condition the same way is outside this bead's areas.
- `scripts/content-inventory.ts` (`selectorBounds` note): the primitive is listed as existing with "X-valued, and relative cost and ✦ bounds", but before this bead `CharacterSelector`'s ✦ bounds were constants only; the existence check matches `costAtLeast` alone. ✦ bounds now take any `BoundValue` (a constant, `x()`, or `countCards`); a ✦ bound relative to another character's ✦ (75bf1aab-dce0-4bbc-8ab0-a3c84b66ae9a) is still missing.
