# hv-umm2.475 pre-existing observations

- `scripts/content-inventory.ts` routes the `banish-self` tag of Wheel of the Heavens (`25d00336-5ad7-433b-8ced-71720a9f074a`) to the existing `banishCards` primitive, and `docs/plan/evidence/content-inventory.json` lists `requiredPrimitives.new: []` for it. `banishCards` names only deck, hand, and void cards (`ZoneCardSpec`), so it cannot name an event on the stack; this bead implements the clause with the new `banishSelfOnResolve` primitive. The inventory script and its JSON are outside this bead's areas and were left unchanged.
- The event-redaction invariant (`src/engine/testing/redaction.ts`, `EventRedaction.check`) marked every card in a deck's final contents as shuffled at that deck's first `shuffledIntoDeck` event of a step. When one step shuffles the same deck twice, as when the active player's part of "each player shuffles their hand and void into their deck" returns an opponent-owned hand card to the opponent's deck before the opponent's own part, the opponent's public void cards were judged hidden at their later `leftVoid` and `shuffledIntoDeck` events. Wheel of the Heavens was the first content to reach it (weighted fuzz: 3 of 300 games). Fixed in this bead's engine-hubs area: a card a later shuffle of the same deck names is not counted as already shuffled; the `banishSelfOnResolve` contracts pin it.
