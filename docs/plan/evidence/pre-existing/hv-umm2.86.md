# Pre-existing issues found by hv-umm2.86

- **Saved-state validation does not check optional turn fields.** `isTurnState` in `src/rules/battle/fold.ts` checks the listed `TurnState` fields and accepts any extra key. The optional `turn.endingCleanup` marker (only `true`, present only while the Ending cleanup waits for its "at end of turn" triggers) is therefore accepted unvalidated in a saved battle; the engine treats any value other than `true` as absent, and `invariantViolations` (`src/engine/testing/invariants.ts`) flags one outside the Ending phase. Smallest fix: `optional(isTrue)(value.endingCleanup)` (or the file's equivalent) in `isTurnState`. Not in this bead's areas; two in-progress beads hold `fold.ts`.
- **A delayed trigger's waiting indicator does not say when it fires or which cards it names.** `engineStatuses` (`src/screens/cumulus_adapters/engine-battle-view-model.ts`, the `"trigger"` case) marks only its controller's side and ignores `change.captured`, and `engineStatusLabel`'s `"delayedTrigger"` copy (`src/runtime/battle-prompt-messages.ts`) reads "A delayed ability is waiting" with no occasion. Borrowed Minutes' cohort therefore shows no "banished at end of turn" mark (judged fail in `docs/plan/evidence/qa-ledger/hv-umm2.86.jsonl`).
