# hv-umm2.757 pre-existing boundaries

Scalar-only mobile deck projection applies permanent modifications before its scalar form, while canonical CardData resolution applies the form first. For example, a base spark of 1 with Kindled and sparkBonus 2 can display 6 through that mobile path and 4 through canonical resolution. Absent-record branches retain their source behavior; chronological-record branches use canonical resolution.

CardData type-change projection retains spark and variable flags across type changes. The actual initialized engine represents Events with null spark, and its existing null-spark to Character branch produces 0 without applying sparkBonus. The catalog.instanceCard comment and public spark-bonus contracts document this compatibility behavior. Chronological-record display agrees with those existing engine contracts. D39's general Event to Character spark question remains a D10 matter; this representation work establishes no additional general rule. The original285/636 type-rule and full-acceptance joins remain intact.

CardData contains authored presentation text and primitive stats, while D36 pending engine sources can be textless and lack authored DSL abilities. Presentation replay cannot certify DSL-sensitive applicability such as Attuned. The production provider validates chronological records against the actual content engine and refuses unavailable or incompatible source claims. Legacy-only injected providers retain their scalar path and cannot validate a present chronological record.

Administrative physical duplication copies its existing explicit field list and omits unrelated debugger statOverride data. Canonical debug resolution treats statOverride as an absolute display override; the actual battle bridge does not transport that debugger field. Chronological records preserve these existing boundaries.

Augury/reward signatures include their existing selected fields plus chronological application identity when present. Other omitted legacy modifications retain their existing signature behavior.
