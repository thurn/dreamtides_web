# Cumulus Revisions Phase 1: Materials and Tokens — Implementation Plan

**Goal:** Make the liquid-glass material and the safe-area channel single-sourced
and token-backed, prune the dead tokens, rename the mis-named opaque-chrome
tokens, tokenize the duplicated disc gradients and atlas rgbas, move
`--cv-textbox-blur` into Cumulus, land the `valid-token-references` ownership
extension, and document Materials + safe-area. Every check green at every commit.

**Architecture:** `src/cumulus/primitives/cumulus-tokens.css` is the source of truth
for tokens; `src/cumulus/primitives/tokens.ts` is a GENERATED mirror
(`scripts/generate-cumulus-tokens.mjs`). The one glass recipe lives in
`src/cumulus/internal/glass-surface.ts` (moved there by Phase 0) and reads tokens
via `token()`. Docs: `.llms/skills/cumulus/` (component pages + `tokens.md` are
generated by `scripts/generate-cumulus-docs.mjs`; `SKILL.md` and a new
`materials.md` are hand-written).

**Tech Stack:** TypeScript + React, CSS custom properties, ESLint custom rules
(`eslint-rules/`), Vitest (`vitest run`), Node ESM generators (`scripts/`).

**Runs after Phase 0**, which has already: moved `glass-surface.ts` and
`control-treatment.ts` to `src/cumulus/internal/` (updating in-cumulus imports and
adding a `no-restricted-imports` guard); created the integrity trio
(`scripts/cumulus-duplicate-literals.test.mjs` and
`scripts/cumulus-orphan-tokens.test.mjs`, each exporting a `const BASELINE`);
added the `no-raw-safe-area-env` and `no-inline-glass` ESLint rules with the
`DraftScreen.tsx:74` ignore in `eslint.config.js`. All paths below use the
post-Phase-0 layout.
